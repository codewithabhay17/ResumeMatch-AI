## Brand & Style

This design system delivers an advanced, high-precision career intelligence experience. It merges analytical data density with futuristic glassmorphism, instilling confidence, authority, and strategic insight for candidates navigating high-stakes career moves. 

The aesthetic is anchored in deep cosmic slate tones layered with translucent, luminous glass panes, subtle electric edge glows, and razor-sharp data displays. Visual depth is established through stacked atmospheric surfaces rather than traditional drop shadows, evoking the feel of an advanced cockpit or high-frequency intelligence terminal. The emotional response is focused, sophisticated, and forward-looking—prioritizing clarity, visual calm, and decisive feedback.

## Colors

The color palette is calibrated for dark mode environments to support extended analytical sessions while preserving visual hierarchy and WCAG AA/AAA compliance across all critical UI surfaces.

### Surface Architecture
- **Deep Background (`#0A0E18`)**: Root viewport background, canvas beneath all views, and backdrop for full-bleed modal layers.
- **Main Background (`#0F131D`)**: Standard dashboard base, sidebar rails, and non-elevated workspace regions.
- **Card Background (`#1C1F2A`)**: Base container tier for cards, modular panels, and persistent navigation components, typically combined with `rgba(28, 31, 42, 0.75)` and backdrop-blur for glass surfaces.
- **Elevated Card (`#262A35`)**: Hover states, popovers, nested sub-modules, and actionable card containers.
- **Highest Surface (`#313540`)**: Floating toolbars, active modal dialogs, contextual tooltips, and elevated control tracks.

### Accents & Intelligence Highlights
- **Primary Accent (`#6366F1` - Electric Indigo)**: Primary brand actions, active state outlines, focus rings, and high-level AI match indices.
- **Secondary Accent (`#06B6D4` - Cyan)**: Real-time telemetry, keyword matches, secondary metric gauges, and algorithmic scanning markers.
- **Tertiary Accent (`#F97316` - Coral/Orange)**: Skill gaps, action-required flags, priority warnings, and critical optimization opportunities.

### Typography & Border Contrast
- **Main Text (`#F8FAFC`)**: High-contrast, maximum prominence text (headlines, core score indicators, primary table values).
- **Secondary Text (`#CBD5E1`)**: Body copy, column headers, descriptive copy, and labeled values.
- **Muted Text (`#94A3B8`)**: Placeholders, disabled states, timestamps, sub-labels, and metadata.
- **Subtle Borders (`rgba(255, 255, 255, 0.08)`)**: Structural boundaries and glass surface edges.
- **Hover/Active Borders (`rgba(99, 102, 241, 0.35)` or `rgba(255, 255, 255, 0.16)`)**: Interactive feedback boundaries.

## Typography

Typography establishes an unambiguous distinction between quantitative analysis and operational workflows:

- **Plus Jakarta Sans** is reserved for headlines, view titles, modal headers, and key analytical metrics (e.g., Match Scores, ATS Compatibility Percentages). Its geometric profile lends modernity, structural strength, and high legibility at large scales.
- **Inter** handles all body content, form fields, dense analytical tables, controls, and microcopy. Its uniform vertical rhythm and neutral geometry ensure maximum legibility across complex multi-column dashboards.
- **Uppercase Badges (`badge-caps`)**: Always set with an expanded letter-spacing (`0.06em`) and bold weight (`700`). Use for machine-learning status chips, ATS scoring vectors, and table attribute classifications.

## Layout & Spacing

This design system uses an **8pt base grid** (with a 4pt half-step for compact metadata rows, badges, and icon alignment) within a fluid, responsive 12-column structure.

### Grid & Layout Breakpoints
- **Desktop (1280px and above)**: 12-column layout, 24px gutters, 40px outer margins. Content maximum width is capped at 1600px for ultrawide panels to preserve scan line lengths. Workspace layouts use a persistent 260px collapsible intelligence sidebar alongside a dynamic master-detail split panel.
- **Tablet (768px – 1279px)**: 8-column layout, 24px gutters, 32px outer margins. Sidebars collapse into an accessible drawer or condensed rail (64px icon-only format). Data tables support horizontal kinetic pan or collapse into stacked cards.
- **Mobile (below 768px)**: 4-column layout, 16px gutters, 16px outer margins. Stacked single-column hierarchy. Glass dashboard panels reflow vertically, with analytical metrics pinned to swipeable top reels.

Vertical cadence must adhere strictly to predefined spacing tokens: cards use `space-lg` (24px) internal padding on desktop and `space-md` (16px) on mobile. Micro-elements (e.g., badge icons, rating dots) utilize `space-2xs` (4px) and `space-xs` (8px).

## Elevation & Depth

Depth is conveyed through **dark glassmorphism, surface luminance, and subtle edge lighting** rather than standard drop shadows, preserving clarity against `#0A0E18`.

### Elevation Hierarchy
1. **Level 0 (Base Canvas - `#0A0E18`)**: Ground surface. Features a subtle, non-distracting radial background gradient (`radial-gradient(circle at 50% 0%, rgba(99, 102, 241, 0.08), transparent 60%)`).
2. **Level 1 (Standard Card & Panel - `#1C1F2A` at 80% opacity)**:
   - Backdrop filter: `blur(16px)`
   - Border: `1px solid rgba(255, 255, 255, 0.08)`
   - Shadow: `0 4px 20px -2px rgba(0, 0, 0, 0.5)`
3. **Level 2 (Elevated Active Card / Hover State - `#262A35` at 90% opacity)**:
   - Backdrop filter: `blur(20px)`
   - Border: `1px solid rgba(255, 255, 255, 0.14)`
   - Shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.65), 0 0 0 1px rgba(99, 102, 241, 0.15)`
4. **Level 3 (Modals, High Popovers, Flyouts - `#313540` at 95% opacity)**:
   - Backdrop filter: `blur(24px)`
   - Border: `1px solid rgba(255, 255, 255, 0.18)`
   - Shadow: `0 24px 48px -8px rgba(0, 0, 0, 0.8), 0 0 24px 0 rgba(99, 102, 241, 0.12)`

### Neon Edge Accent Rule
Interactive and critical elements (such as active dropzones, focused inputs, or top-tier match cards) incorporate a directional gradient border using linear interpolation: `linear-gradient(135deg, rgba(99, 102, 241, 0.6) 0%, rgba(6, 182, 212, 0.2) 50%, rgba(255, 255, 255, 0.05) 100%)`.

## Shapes

The design system employs a **Rounded** shape philosophy (Level 2) with a deliberate architectural hierarchy:

- **Standard Elements (0.5rem / 8px)**: Standard buttons, input fields, dropdown trigger targets, table rows, and tooltips.
- **Containers & Modules (1rem / 16px - `rounded-lg`)**: Resume cards, intelligence panels, dashboard charts, analytics sections, and dialog modals.
- **Nested Inner Surfaces (0.75rem / 12px)**: Sub-panels, code blocks, highlighted skill clusters, and parsed resume excerpts sitting inside a main card.
- **Pill Shapes (`rounded-full`)**: Analytical status chips, keyword tags, category pills, avatar frames, and floating status indicators.

## Components

### Buttons
- **Primary**: Solid Electric Indigo (`#6366F1`) background, Main Text (`#F8FAFC`), font weight 500 (`label-md`). Hover transitions to `#4F46E5` with a subtle luminous glow (`box-shadow: 0 0 16px rgba(99, 102, 241, 0.4)`). Active state scales down subtly to `0.98`.
- **Secondary (Glass)**: Semi-transparent `#262A35` with `1px solid rgba(255, 255, 255, 0.12)`. Hover shifts background to `#313540` and border to `rgba(255, 255, 255, 0.2)`.
- **Tertiary / Ghost**: Transparent background with Secondary Text (`#CBD5E1`). Hover produces `rgba(255, 255, 255, 0.05)` fill with Main Text (`#F8FAFC`).

### Chips & Analytical Badges
- **Status/Metric Chips**: Pill-shaped (`rounded-full`), padding `4px 10px`, typography set to `badge-caps`.
- **Cyan Variant (Matched Keyword / Verified ATS)**: `rgba(6, 182, 212, 0.12)` background, `#06B6D4` text, border `1px solid rgba(6, 182, 212, 0.3)`.
- **Coral Variant (Skill Gap / Missing Keyword)**: `rgba(249, 115, 22, 0.12)` background, `#F97316` text, border `1px solid rgba(249, 115, 22, 0.3)`.
- **Neutral Variant**: `rgba(255, 255, 255, 0.05)` background, `#CBD5E1` text, border `1px solid rgba(255, 255, 255, 0.08)`.

### Cards & Intelligence Panels
- Base background `#1C1F2A` (80% opacity) with `16px` backdrop blur, `rounded-lg` (16px radius), and `rgba(255, 255, 255, 0.08)` border.
- Cards must feature clear visual zoning: a distinct header zone with `space-md` bottom border separation, a flexible body data zone, and an optional footer housing contextual action links or micro-scores.

### Input Fields & Search Bars
- Background `#161922`, `rounded` (8px), border `1px solid rgba(255, 255, 255, 0.12)`. Height is fixed at 40px for standard inputs, 48px for primary search bars.
- Placeholder text uses Muted Text (`#94A3B8`). Focus state switches border to `#6366F1` and adds an outer ring: `0 0 0 2px rgba(99, 102, 241, 0.25)`.

### Checkboxes & Selection Controls
- Checkbox box size `18px`, `rounded` (4px), border `1px solid rgba(255, 255, 255, 0.2)`.
- Checked state fills with `#6366F1` featuring a crisp white SVG check icon. 
- Radio buttons feature an inset cyan (`#06B6D4`) dot surrounded by `#161922` container ring when selected.

### Lists & Data Rows
- Resume and job match lists use alternating transparent rows with clean separator lines (`1px solid rgba(255, 255, 255, 0.04)`).
- Hovering over a row highlights it with `#262A35` at 50% opacity and adds an electric indigo 2px accent indicator along the left edge.

### Specialized AI & Career Components
- **ATS Match Radial Meter**: Circular SVG progress gauge using Cyan (`#06B6D4`) transitioning to Electric Indigo (`#6366F1`), centered with a `metric-md` score.
- **Skill Matrix Heatmap**: Compact grid with cell backgrounds shifting dynamically from `rgba(255, 255, 255, 0.03)` (absent) to `rgba(6, 182, 212, 0.4)` (exceptional match).
- **Resume Parsing Dropzone**: Large translucent panel with dashed border `rgba(99, 102, 241, 0.35)` and subtle idle pulsing glow, shifting to solid `#6366F1` and `rgba(99, 102, 241, 0.08)` background fill during drag-over.
